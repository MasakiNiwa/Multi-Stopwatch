## v0.4 コンパクト一覧とテーマ選択（2026-09-13 / Claude）

### 一覧の作り直し

カード型（1件297px、390×844で完全に見えるのは1件）を、1件1行のコンパクト表示に置き換えた。
1行66px。**390×844で4件なら4件すべて、10件でも6件が固定ツールバーの上に収まる**。10件の総高さは2397px→1270px。

行の構成は左から、並べ替えハンドル、開始/停止、名前＋状態、右端に時間。2行目は行幅いっぱいを使い、目標の残り％かメモを表示する。
旧Flutter版と同じく「時間と名前が一行に並ぶ」形に戻し、単位付き表示（`00h00m00s`）は継承した。

**通常表示との切替は作らず、常時コンパクトにした。** 切替は設定と説明が増える割に、隠れた情報（メモ・目標の正確な値・低頻度操作）は
詳細画面ですべて読めるため。実画面で比較した結果、切替の必要性を感じなかった。必要なら「ゆったり表示」を後から足せる。

### 目的の計測を見つける・並べ替える

- **絞り込み**：6件以上で名前・メモの検索欄を出す。全角半角と大文字小文字を無視して一致（`matches`）。「10件中1件を表示」と件数を出す
- **並べ替え**：行左端のハンドルをドラッグ（マウス・タッチ共通のPointer Events、画面端では自動スクロール）。
  同じハンドルにフォーカスして**上下キー**でも移動でき、押しっぱなしでも連続で動く。詳細画面にも「↑上へ移動／↓下へ移動」を置いた
- 絞り込み中はハンドルを無効化する。隠れている行との前後関係が決められないため。理由をtitleに出している
- 並べ替えは操作直後に保存し、再読込後も維持する

### 低頻度操作の整理

編集・リセット・削除・並べ替えを行から外し、名前部分を押して開く**詳細画面**に集約した。行に残したのは開始/停止とハンドルだけ。
詳細画面は計測中も時間が動き、閲覧専用のウィンドウでは中身を読めるが操作ボタンは無効になる。

### テーマ選択

- ヘッダーに「端末／ライト／ダーク」の3択。初期値はsystem

- `<meta name="theme-color">` はJSが1つだけ管理し、選択テーマに追従する。manifestの `theme_color` / `background_color` はライト側の色に揃えた（standaloneの起動画面は静的なため）
- 端末設定に追従するモードでは、OSのライト/ダーク変更に即座に追従する

## v0.5 グループ・一括並べ替え・統計（2026-09-13 / Claude）

次の担当：**ChatGPT（ディレクター兼レビュアー）**。Issue #6 の実装です。mainへはマージしていません。

進め方はissueの指示どおり、schema/移行と純粋関数 → UI → Playwrightとスクリーンショット、の順で進めました。

### schema v2と移行

- `{version:2, timers:[{…, groupId}], groups:[{id,name}]}`。`groupId` は null か実在するグループid。存在しないidは `validate` が拒否
- `migrate` は純粋関数。v1の各タイマーに `groupId: null` を足すだけで、時間・稼働状態・順序・目標をそのまま持ち越す
- **読み込み時に移行するが書き戻さない。** 次に何か保存した時点でv2として書かれる。読むだけで記録を書き換えないほうが、閲覧専用の画面や事故時の復旧に都合がよいと判断した
- 保存キーは `multi-stopwatch:state:v1` のまま。キーは記録の名前で、schemaの版は値の中の `version` が持つ。キーを変えると既存の記録が孤立する
- 書き出しはv2、読み込みはv1/v2の両方

### 一括並べ替え

11条件。`select` で条件を選び「並べ替える」を押すと**その時点で全件へ一度適用して保存**する。選ぶだけでは並ばない方式にしたのは、手動で整えた順序を誤操作で失わないため。適用後もドラッグと上下キーで微調整できる。
絞り込み中でも全件に適用し、件数と条件をaria-liveで通知する。同値は適用前の順序を保つ安定sort。

### 統計

各タイマーが今持っている累計の集計のみ。issueのとおりセッション履歴は扱わない。
全体累計、計測中/全件、グループ別小計と割合、累計時間ランキング（順位・名前・グループ・時間・割合）。棒はCSSで、色だけに意味を持たせず時間・順位・割合を文字でも出す。

### レイアウト

`(orientation: landscape) and (min-width: 800px)` で2カラム、それ以外はARIAのタブ。2カラムのときはタブを隠して両方をregionにする。
`auto/tab/panel` の手動設定はissueで任意とされていたため入れていない。設定を増やす前に、自動切替の不満を実使用で見たい。

### 判断が要る点（ChatGPTに見てほしい）

1. **移行を読み込み時に書き戻さない**判断。閲覧専用の画面や復旧には有利だが、「いつv2になるか」がユーザーから見えない
2. **保存キーを `…:v1` のまま**にしたこと。名前とschemaの版がずれる。改名するなら移行処理が要る
3. **並べ替えは明示的な「適用」操作**にしたこと（選択即適用にしなかった）
4. **高さの低い横画面で、2カラムのときだけヒーローの合計を隠す**こと。統計パネルと重複するため
5. **手動レイアウト設定（auto/tab/panel）を入れていない**こと。prefsをv2へ上げる必要があるため見送った
